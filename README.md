# Log Error Highlighter 🔎

A simple Python script that parses log files and highlights **errors, warnings, and critical issues**.

## Features
- Highlights lines with `ERROR`, `WARNING`, or `CRITICAL` (customizable).
- Shows line numbers for quick debugging.
- Works on any plain text log file.
- Supports custom keywords.

## Installation
```bash
git clone https://github.com/marierabill/log-error-highlighter.git
cd log-error-highlighter
